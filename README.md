# DamDays

Calibrated per-dam drought-runway forecasts for farm dams, built from 38 years of satellite water history, plus a season-ahead water-security rating.

Climate Hack-tion 2026 (Build for 2035), COP31 track: Awareness Across All Areas (farmers adapting to drought).

Work in progress during the event. See PREREG.md (the pre-registered evaluation) and DISCLOSURE.md.
